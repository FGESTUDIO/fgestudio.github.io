# Third-Party Reuse Register

Record any external code, library, component, template, asset or implementation materially reused or adapted in this project.

For each entry record:
- Name
- Source URL/repository
- Version / commit
- License
- What was reused
- Integration type: dependency / copied-and-modified / ported / reference-only
- Local modifications
- Attribution / NOTICE requirements
- Upgrade or security notes

## Rules
Prefer clear licenses, active maintenance and compatibility with the current project.
Do not copy code/assets with unclear or incompatible rights.
Do not import an entire project when only a small component is needed.
